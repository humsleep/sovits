# 온음 — 내 목소리 TTS (MacBook Air M2)

엔진: **고품질 = Qwen3-TTS 1.7B (Apache-2.0, MLX)** 기본 / **빠른 모드 = GPT-SoVITS v2Pro**. 스튜디오 오른쪽 '음성 엔진'에서 바꿀 수 있습니다.
기본 제공 목소리 8종(남녀 어린이·학생·성인, 할아버지·할머니)은 `presets/` 에 있으며, 실제 사람이 아닌 AI(Qwen3-TTS VoiceDesign)로 만든 목소리입니다.

녹음과 텍스트는 이 맥 밖으로 나가지 않습니다. 무료입니다.
(인터넷 사용: '자동 받아쓰기'를 처음 쓸 때 받아쓰기 모델(약 460MB)을 한 번 내려받습니다.)

## 설치 (처음 한 번)
Apple Silicon Mac, Homebrew, 디스크 약 15GB가 필요합니다.
```
git clone https://github.com/humsleep/sovits.git && cd sovits && ./setup.sh
```
- 빠른 모드 엔진 GPT-SoVITS(고정 커밋)와 모델, 고품질 엔진 Qwen3-TTS(MLX)와 모델을 내려받습니다.
- 정확한 패키지 버전은 `requirements/*-lock.txt` 에 있습니다.
- 개인 데이터(`voices/` 내 목소리, `out/` 기록, `settings.json`)는 저장소에 포함되지 않습니다.

## 웹 앱 (추천)
1. `start.command` 더블클릭 → 브라우저가 자동으로 열립니다 (http://127.0.0.1:7860). 끄려면 `end.command` 더블클릭 (또는 터미널 창 닫기).
   - 처음 한 번은 macOS 가 막을 수 있습니다: 우클릭 → 열기.
2. **내 목소리 등록** 탭: 화면의 문장을 읽어 녹음(5~9초) → 등록.
3. **말하기** 탭: 텍스트 입력 → "내 목소리로 읽기".
4. **기록** 탭: 최근 300개 음성 다시 듣기/다운로드. 파일은 `out/history/` (오래된 것부터 자동 삭제).
5. **발음 사전** 탭: 자주 틀리는 단어의 읽는 법 등록 (예: ChatGPT → 챗지피티).

20분 동안 사용하지 않으면 모델을 메모리에서 내리고(약 1GB 회수), 다음 요청 때 다시 불러옵니다.
보안: 앱은 이 맥의 브라우저(127.0.0.1:7860)와 로컬 프로그램 요청만 받고, 다른 웹사이트에서 오는 요청은 차단합니다.
7860 포트를 다른 프로그램이 쓰고 있으면 실행 창에 안내가 나옵니다.

## 명령줄
```
./prep_ref.sh 녹음.m4a "녹음에서 읽은 문장" [목소리이름]
./speak.sh "읽을 문장" -o out/결과.wav [--voice 기본] [--speed 1.1]
./speak.sh -f 대본.txt -o out/대본.wav
./speak.sh -- "-5도까지 내려갑니다"     # '-'로 시작하는 문장
```
웹 앱이 켜져 있으면 speak.sh 가 앱에 요청해 모델 로딩 없이 바로 처리합니다 (`--local` 이면 직접 합성, 메모리 추가 사용).
`--seed 숫자` 로 억양을 바꿔볼 수 있습니다 (기본 42 = 같은 입력이면 같은 결과, -1 = 매번 무작위).

## 선택한 텍스트를 내 목소리로 읽기 (macOS 단축어)
단축어 앱 → 새 단축어 → '셸 스크립트 실행' 추가 → 입력: 단축어 입력(텍스트), 입력 전달: stdin →
스크립트: `<이 폴더 경로>/say_selection.sh` (예: ~/workspace/sovits/say_selection.sh) → 단축어 설정에서 '서비스 메뉴에서 사용' 켜기.
클립보드 읽기: `pbpaste | ./say_selection.sh`

## 설정 (engine.py 의 DEFAULTS)
v2Pro 모델, CPU 4스레드, top_k 5, temperature 0.6, seed 42 — M2 Air 실측 기준 최적값.
